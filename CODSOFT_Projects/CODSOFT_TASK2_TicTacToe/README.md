# CODSOFT Task 2 - Tic-Tac-Toe AI

Play Tic-Tac-Toe against an unbeatable AI built with the Minimax algorithm
and Alpha-Beta Pruning.

## Run
```
python tictactoe.py
```

## How it works
- Minimax explores every possible future game and assumes both players play optimally.
- AI win = positive score, human win = negative score, draw = 0.
- Alpha-Beta Pruning skips branches that cannot affect the final decision, making search faster.
- Best you can do against it is a draw.
